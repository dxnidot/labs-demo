# Decisiones

## Plantilla ADR corta

### ADR-000X: Título

- Contexto: qué problema o necesidad motivó la decisión.
- Decisión: qué se va a hacer.
- Alternativas consideradas: otras opciones y por qué no.
- Consecuencias: beneficios, costos y riesgos.
- Estado: Propuesta | Aceptada | Rechazada | Obsoleta | Parcialmente reemplazada por ADR-XXXX.
