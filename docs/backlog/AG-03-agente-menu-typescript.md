- Estado: Pendiente

- Depende de: AG-01

- Contexto: El agente de menú responde información sin tomar decisiones complejas. La idea es mantenerlo ligero, con una tool local y con A2A para que el orquestador lo use según el contexto del usuario.
- Criterio de aceptación:
  - `curl http://localhost:8003/.well-known/agent-card.json` devuelve una card con name "menu" y la descripción esperada del servicio.
  - `cd agents/menu-ts && npm test -- --run` pasa la prueba del tool que devuelve las opciones del menú.
  - Una consulta de menú devuelve una lista de opciones del usuario y no se usa el LLM para decidir la lógica de negocio del flujo.
- Archivos relevantes:
  - agents/menu-ts/
  - agents/orquestador/

  - Inferido: la ultima versión del paquete del SDK puede cambiar el nombre del servicio o del endpoint.
