# Backlog

## Plantilla

### Título

- Estado: Pendiente | En curso | Hecho
- Prioridad: Alta | Media | Baja
- Contexto: breve descripción del problema o necesidad.
- Resultado esperado: qué debe quedar al cerrarse la tarea.
- Archivos relevantes: rutas del repo o documentos asociados.
- Notas: comentarios, riesgos o dependencias.
